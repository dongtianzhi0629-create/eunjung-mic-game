# 拯救大兵恩静计划

这是一个静态网页小游戏部署包。

## 本地预览

直接打开 `index.html` 即可试玩。

## Vercel 部署

1. 将本目录推送到 GitHub 仓库。
2. 在 Vercel 导入该仓库。
3. Build Command 留空。
4. Output Directory 使用根目录。
5. 部署完成后测试手机和微信内置浏览器。

## 文件说明

- `index.html`：游戏入口。
- `assets/`：音频、角色、手、生命值等素材。
- `vercel.json`：Vercel 静态缓存配置。
- `DEPLOY_PLAN_A.md`：方案 A 上线说明。
